# Backend (Supabase)

Design: [BACKEND_PLAN.md](../BACKEND_PLAN.md). Progress: [backend_progress.md](../backend_progress.md).

- `supabase/` — CLI project (`config.toml`, `migrations/`, `functions/`). Run CLI commands from this folder.
- `contracts/` — generated by `codegen` (`database.types.ts`, `errors.ts`). Never edit by hand.
- `tests/` — Edge Function and load tests.
- SQL source of truth lives in `../database/schema/<module>/` (applied in order: tables, functions, triggers, rls, grants).

Scripts (need `DB_URL` and `psql`; scripts use POSIX sh, so on Windows run them from Git Bash):

| Script | Does |
|---|---|
| `db:apply` | Applies `database/schema` modules in folder order |
| `db:seed` | Loads `database/seed/reference/*.sql` |
| `db:test` | Runs pgTAP files `database/tests/*.test.sql`; fails on any `not ok` |
| `codegen` | Writes `contracts/database.types.ts` and `contracts/errors.ts` from the local DB |
| `codegen:check` | Fails if `contracts/` differs from git (CI drift check) |

No Docker on the dev PC: these run in GitHub Actions (`.github/workflows/ci.yml`).
